# 个人工作站小程序

## 项目介绍
这是一个基于微信小程序云开发的个人工作站应用，用户可以在这里记录和管理自己的笔记内容，支持文字和图片的混合记录方式。同时提供用户信息管理功能，让用户可以个性化自己的工作站。

## 主要功能
- 笔记管理：创建、编辑、删除笔记
- 图片上传：支持每条笔记最多上传9张图片
- 图片预览：支持查看已上传的图片
- 下拉刷新：支持列表页面的下拉刷新
- 加载更多：支持列表页面的上拉加载更多
- 用户管理：支持用户信息的查看和编辑

## 开发环境
- 微信开发者工具
- 微信小程序基础库 2.30.0 或以上版本
- 开通微信云开发

## 配置说明
1. 在微信开发者工具中创建小程序项目
2. 开通云开发，获取云环境ID
3. 在 `app.js` 中配置云环境ID：
```javascript
wx.cloud.init({
  env: 'your-env-id',  // 替换为你的云环境ID
  traceUser: true
})
```

## 数据库设计
### content 集合
用于存储笔记内容

字段说明：
- `_id`: 文档ID（系统自动生成）
- `text`: 文本内容
- `imageList`: 图片文件ID数组
- `createTime`: 创建时间
- `updateTime`: 更新时间

### user 集合
用于存储用户信息

字段说明：
- `_id`: 文档ID（系统自动生成）
- `openid`: 用户的唯一标识
- `avatarUrl`: 用户头像地址
- `nickName`: 用户昵称
- `updateTime`: 更新时间

## 使用说明
1. 首页
   - 点击「新建笔记」创建新的笔记
   - 下拉可以刷新笔记列表
   - 上拉可以加载更多笔记
   - 点击笔记中的图片可以预览
   - 点击「删除」可以删除笔记

2. 编辑页
   - 在文本框中输入笔记内容
   - 点击「+」添加图片（最多9张）
   - 点击图片右上角的「×」可以删除图片
   - 点击「保存」保存笔记

3. 用户页
   - 显示用户基本信息
   - 支持修改用户头像和昵称
   - 展示用户的笔记统计信息

## 注意事项
1. 图片上传限制
   - 每条笔记最多支持9张图片
   - 建议上传压缩后的图片以提高性能

2. 云环境配置
   - 确保云环境已开通
   - 配置正确的云环境ID
   - 设置适当的云存储和数据库权限

3. 用户信息
   - 首次使用需要授权获取用户信息
   - 用户信息仅用于显示，不会用于其他用途

## 维护说明
1. 代码结构
   - 遵循微信小程序开发规范
   - 使用模块化的方式组织代码
   - 各个功能模块都有详细的注释说明

2. 样式管理
   - 全局样式在 app.wxss 中定义
   - 页面特定样式在对应的 wxss 文件中定义
   - 使用BEM命名规范管理样式

3. 数据管理
   - 使用云开发数据库存储数据
   - 图片资源存储在云存储中
   - 注意定期清理无用的云存储资源
